## 已评审决定（2026-11-21）

1. 演示环境允许角色兼任，正式项目采用单人单项目单职责，任何模式下不得自审。
2. 增加UAT截图、报告附件上传、图片预览、类型/体积限制和项目权限控制。
3. 上线门禁包含高风险缺陷、8项UAT独立验收、最新数据质量、风险接受、安全复核、回滚及恢复验证、交付文档和运维交接；申请与审核分人。

## 重要边界

- `VERIFLOW_MODE=production` 是**角色策略标签**，不代表系统已经具备真实公网生产安全性。
- 图片可以受控预览；PDF只提供受控下载，在线预览留待安全方案评审后实现。
- 文件校验和私有存储只是基础措施；没有防病毒、对象存储、文件生命周期管理或安全审计，不可上传真实医疗或客户文件。
- 原ChatGPT Sites私人演示网页**未被修改**；v0.3独立打包，尚未推送到用户GitHub或独立公网部署。
- 本轮完成20项后端自动化测试；尝试访问本地站点的浏览器受运行环境限制，**不能据此宣称人工UI验收通过**。
